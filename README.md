# SiQUENCER releases

Downloads for **SiQUENCER**, a four-track MIDI step sequencer (VST3 + standalone app) by Obscura Lux.

Go to **[Releases](../../releases/latest)** and download `SiQUENCER-Beta-<version>-macOS.dmg`
(macOS 12 or later, Apple Silicon and Intel). SiQUENCER needs a license file to play.

SiQUENCER checks this page for new versions and can install them by itself (Options ▸ Updates).
Each release includes `siquencer-update.json`, which lists the update package with its size and
SHA-256 hash, and `siquencer-update.json.sig`, an RSA signature of that file. SiQUENCER installs an
update only if the signature, the hash and the Apple Developer ID code signature all check out.
